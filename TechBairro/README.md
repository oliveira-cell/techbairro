# TechBairro

Sistema de cadastro e gerenciamento de moradores e clientes para associações de bairro, desenvolvido para facilitar o atendimento diário e o controle de cadastros.

**Versão atual:** 1.0.0 · Histórico de mudanças no [CHANGELOG](CHANGELOG.md)

## Funcionalidades
- Cadastro completo de novos clientes com validação de campos.
- Consulta rápida de moradores cadastrados.
- Alteração e atualização de dados de clientes existentes.
- Exclusão segura de registros do sistema.

## Requisitos para execução
| Item | Requisito |
|---|---|
| Sistema operacional | Windows, macOS ou Linux |
| Python | Versão 3.10 ou superior (versão testada: 3.11.4) |
| Tkinter | Já incluso na instalação padrão do Python |
| Bibliotecas externas | Nenhuma (utiliza apenas a biblioteca padrão) |
| Internet | Não necessária para execução local |

## Instalação
1. Certifique-se de ter o Python instalado em seu computador.
2. Baixe o projeto de uma das duas formas:
   - **Com Git:** Abra o terminal e digite `git clone [https://github.com/seu-usuario/techbairro.git](https://github.com/seu-usuario/techbairro.git)`
   - **Sem Git:** Clique no botão verde **Code** no GitHub, escolha **Download ZIP**, extraia o arquivo ZIP em uma pasta no seu computador e abra o terminal dentro dessa pasta.
3. No terminal, navegue até a pasta do projeto e execute o comando:
   ```bash
   python techbairro.py

TechBairro 3.2.1
Requisitos
- Python 3 (testado com Python 3.21.0 no windows)
- Nenhuma biblioteca extra: usa apenas Tkinter, sqlite3 e os,
que já vêm com o Python
- No Linux pode ser preciso instalar o Tkinter: sudo apt install python
3-tk
Como executar
1. Extraia o arquivo TechBairro-3.2.1.zip
2. Abra um terminal dentro da pasta TechBairro-3.2.1
3. Execute: python techbairro.py
Dados
- Na primeira execução, o arquivo techbairro.db é o vazio na mesma pasta.
- Faça cópias desse arquivo para não perder os clientes cadastrados.

Histórico do código
O projeto usa Git. Para ver o histórico, rode na pasta do p
rojeto:
git log --oneline
